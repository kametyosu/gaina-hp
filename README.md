# 有限会社ガイナ電気 ホームページ

日本語のレスポンシブな企業紹介サイトです。HTML/CSS/JavaScript で動作し、依存パッケージやビルドは不要です。

## ローカル起動

```sh
cd /workspace/gaina-hp
python3 -m http.server 8000 --bind 0.0.0.0
```

## 編集

- `index.html`: 事業内容、会社紹介、ページ構成
- `style.css`: 色、レイアウト、スマートフォン対応
- `animation.js`: 電気をつなぐ体験図の点灯・消灯制御（動きを減らす設定に対応）

採用条件と応募用メールを掲載しています。所在地・給与・施工実績などは未確認のため掲載していません。電話番号として提示された 090-0000-0000 は仮番号と考えられるため未掲載です。ロゴは提供画像を参考にした仮のSVGで、正式な元画像へ差し替える必要があります。
画像や外部フォントへの通信はありません。静的ホスティングにそのまま配置できます。
