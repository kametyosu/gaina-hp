# 有限会社ガイナ電気 ホームページ

日本語のレスポンシブな企業紹介サイトです。HTML/CSS のみで動作し、依存パッケージやビルドは不要です。

## ローカル起動

```sh
cd /workspace/gaina-hp
python3 -m http.server 8000 --bind 0.0.0.0
```

## 編集

- `index.html`: 事業内容、会社紹介、ページ構成
- `style.css`: 色、レイアウト、スマートフォン対応

所在地・電話番号・メールアドレス・施工実績・資格などは未確認のため掲載していません。確認済みの情報を追加してから公開してください。
画像や外部フォントへの通信はありません。静的ホスティングにそのまま配置できます。
