# 有限会社ガイナ電気 採用サイト

HTML/CSS/JavaScript の静的サイトです。依存パッケージやビルドは不要です。

## 起動

```sh
cd /workspace/gaina-hp
python3 -m http.server 8000 --bind 0.0.0.0
```

使用中のポートがある場合は既存サーバーを確認するか、別のポートを指定してください。

## ファイル

- `index.html`: 現場紹介、図解、工事内容、規模・エリア、採用相談
- `style.css`: レスポンシブデザイン
- `animation.js`: メールアドレスのコピー機能（旧点灯アニメーションは撤去）
- `assets/recruit-work.webp`: AI生成の工事イメージ。自社の現場写真ではなく、画面にも明記
- `assets/gaina-logo.svg`: 提供された画像を参考にした仮のロゴ。正式な元画像への差し替えが必要

募集条件とメールアドレスは提供情報に基づきます。給与、所在地、具体的な工事項目、現場人数・工期など、未確認の情報は作成していません。電話番号 `090-0000-0000` は仮番号と考えられるため未掲載です。

Netlify はブランチ `main`、ビルドコマンドなし、公開ディレクトリ `.` で配信できます。
